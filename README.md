# gif-to-png
Extracting GIF frames into PNG

The GIF I used is not mine, but belongs to a pixel artist named Zedotagger;
go check them out! I was only using their GIF as an example of how to extract a GIF into PNGs :)

HOW TO USE:

To run the code, you of course need to install Python and Pillow.

1. Install Pillow (if you haven't already):
    pip install Pillow

2. Put your GIF in the same folder as the script.

3. Update the filename in the script:
     gif_file = "example.gif"

4. Run the script:
     python gif_to_png.py
